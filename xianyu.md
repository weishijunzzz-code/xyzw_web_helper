# XYZW Web Helper - 业务逻辑梳理文档

## 一、项目概述

**项目名称**: XYZW Web Helper（咸鱼之王游戏助手）  
**技术栈**: Vue 3 + TypeScript + Vite + Pinia  
**部署平台**: Cloudflare Pages  
**核心功能**: 通过 WebSocket 连接游戏服务器，实现游戏账号管理、自动化任务执行、实时监控等功能。

---

#### 2.1.4 Token 分组管理

```typescript
interface TokenGroup {
  id: string;           // 分组唯一标识
  name: string;         // 分组名称
  color: string;        // 分组颜色（UI 显示）
  tokenIds: string[];   // 属于该分组的 Token ID 列表
  createdAt?: string;   // 创建时间
  updatedAt?: string;   // 更新时间
}
```

**分组操作**:
- `createTokenGroup(name, color)` - 创建分组
- `addTokenToGroup(groupId, tokenId)` - 添加 Token 到分组
- `removeTokenFromGroup(groupId, tokenId)` - 从分组移除 Token
- `getValidGroupTokenIds(groupId)` - 获取分组中有效的 Token ID

#### 2.2.2 连接创建流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    WebSocket 连接创建流程                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 获取连接锁 (acquireConnectionLock)                          │
│     └── 防止并发创建同一 Token 的连接                            │
│                                                                 │
│  2. 检查跨标签页连接状态 (checkCrossTabConnection)              │
│     └── 如果其他标签页已连接，跳过创建                          │
│                                                                 │
│  3. 更新跨标签页状态为 connecting                               │
│     └── 通知其他标签页当前正在连接                              │
│                                                                 │
│  4. 关闭现有连接 (closeWebSocketConnectionAsync)                │
│     └── 优雅关闭，等待连接完全断开                              │
│                                                                 │
│  5. 解析 Token (parseBase64Token)                               │
│     └── 提取实际用于连接的 Token 字符串                          │
│                                                                 │
│  6. 构建 WebSocket URL                                          │
│     └── wss://xxz-xyzw.hortorgames.com/agent?p={token}&e=x...   │
│                                                                 │
│  7. 创建 XyzwWebSocketClient 实例                               │
│     └── 配置 URL、工具类、心跳间隔                              │
│                                                                 │
│  8. 设置事件监听器                                               │
│     ├── onConnect: 更新状态为 connected，发送 role_getroleinfo │
│     ├── onDisconnect: 处理断开逻辑，检测是否需要刷新 Token       │
│     └── onError: 记录错误信息                                    │
│                                                                 │
│  9. 设置消息监听器                                               │
│     └── 接收游戏服务器消息，分发到事件系统                       │
│                                                                 │
│  10. 初始化连接 (wsClient.init())                               │
│      └── 建立 WebSocket 连接，开始心跳检测                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.3 批量任务执行业务逻辑

#### 4.3.1 DailyTaskRunner 类

```typescript
class DailyTaskRunner {
  constructor(tokenStore, options) {
    this.tokenStore = tokenStore
    this.commandDelay = options.commandDelay || 1000
    this.taskDelay = options.taskDelay || 2000
  }

  async run(tokenId, callbacks) {
    const { onLog, onProgress } = callbacks
    
    // 1. 确保连接
    await this.ensureConnection(tokenId)
    
    // 2. 获取任务列表
    const tasks = this.getSelectedTasks()
    
    // 3. 顺序执行任务
    for (const task of tasks) {
      onLog(`开始执行: ${task.name}`)
      
      try {
        await this.executeTask(tokenId, task)
        onLog(`执行成功: ${task.name}`)
      } catch (error) {
        onLog(`执行失败: ${task.name} - ${error.message}`)
      }
      
      // 任务间延迟
      await this.delay(this.taskDelay)
      onProgress(task.id, true)
    }
    
    // 4. 断开连接
    this.tokenStore.closeWebSocketConnection(tokenId)
  }

  async executeTask(tokenId, task) {
    switch (task.id) {
      case 'daily_signin':
        return this.tokenStore.sendMessageWithPromise(
          tokenId, 
          'system_signinreward'
        )
      case 'tower_challenge':
        return this.executeTowerChallenge(tokenId)
      // ... 更多任务
    }
  }
}
```

#### 4.3.2 并发控制

```typescript
// 使用 P-Queue 控制并发
import PQueue from 'p-queue'

const queue = new PQueue({ 
  concurrency: maxConcurrent || 3  // 最大并发数
})

// 批量执行
const batchExecute = async (tokenIds, tasks) => {
  const promises = tokenIds.map(tokenId => {
    return queue.add(async () => {
      const runner = new DailyTaskRunner(tokenStore, options)
      return runner.run(tokenId, { 
        onLog: (msg) => addLog(tokenId, msg),
        onProgress: (taskId, success) => updateProgress(tokenId, taskId, success)
      })
    })
  })
  
  await Promise.all(promises)
}
```

## 六、技术实现要点

### 6.1 关键技术选型

| 技术 | 用途 | 说明 |
|------|------|------|
| Vue 3 | 前端框架 | Composition API + 响应式系统 |
| TypeScript | 类型安全 | 核心逻辑使用 TS 编写 |
| Pinia | 状态管理 | 替代 Vuex，更轻量 |
| VueUse | 工具集 | useLocalStorage 等 |
| idb | IndexedDB | 浏览器本地数据库 |
| EventEmitter3 | 事件系统 | 游戏消息分发 |
| P-Queue | 队列控制 | 批量任务并发控制 |
| Protocol Buffer | 消息编码 | 与游戏服务器通信 |

### 6.2 性能优化策略

1. **连接池管理**: 限制最大并发连接数，避免过多连接导致浏览器性能问题
2. **消息队列**: 使用 P-Queue 控制批量任务的并发执行
3. **延迟执行**: 任务间添加延迟，避免请求过于频繁
4. **懒加载**: 路由组件懒加载，减少首屏加载时间
5. **IndexedDB**: 大容量二进制数据存储，避免 localStorage 大小限制

### 6.3 安全考虑

1. **Token 存储**: 敏感数据仅存储在用户浏览器本地，不上传到服务器
2. **CORS 代理**: 通过 Cloudflare Worker 代理请求，避免跨域问题
3. **输入验证**: Token 导入时进行格式和长度验证
4. **XSS 防护**: Vue 模板自动转义，避免 XSS 攻击

## 七、总结

本文档详细梳理了 XYZW Web Helper 项目的所有核心业务逻辑，包括:

1. **Token 管理模块**: 多种导入方式、分组管理、自动刷新机制
2. **WebSocket 连接模块**: 连接状态机、消息编解码、跨标签页同步
3. **游戏功能模块**: 日常任务、爬塔系统、答题系统、批量执行

项目采用现代化的 Vue 3 技术栈，通过 WebSocket 与游戏服务器实时通信，实现了游戏账号的自动化管理功能。所有敏感数据均存储在用户本地，保证了数据安全性。
